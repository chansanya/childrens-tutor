# 小问号学伴 · 第三方接入指南

小问号学伴是面向 6–12 岁儿童的 AI 学伴。你的系统可以通过 HTTP 接口向它提一个问题，拿回一段经过安全审查、适合儿童的回答。

接口兼容 **OpenAI Responses API**，可以直接用 OpenAI 官方 SDK（Node.js、Python 等）调用，也可以用任意 HTTP 客户端调用。仓库中的 [examples/node-client.mjs](../examples/node-client.mjs) 是一份完整的 Node.js 示例，包含异常处理、metadata 处理和测试模式。

## 先了解这几点

- **一问一答**：每次请求都是独立的，服务端不保存会话，也不会读取你传来的历史对话。
- **只返回审查后的结果**：每个回答都经过意图审查和输出审查。支持流式输出，但同样是审查通过后才开始推送文字，首字等待时间与非流式相同。
- **回答不一定是"答案"**：遇到写作文、做作业题这类请求，学伴只会引导思路，不会代写；遇到试图绕过规则或不适合儿童的话题，会给出拒绝或安全提示。可以通过返回结果里的 `metadata.path` 和 `metadata.guided` 区分。
- **不会返回审查故障**：安全审查服务暂时不可用时，接口不会报错，而是正常返回一句兜底话术（`path=guard_error`）。客户端照常展示即可。
- **可能会画画**：问题是"帮我画一只小猫"这类请求时，会生成图片并返回图片地址，耗时可能达到几十秒。

## 接入步骤

1. **申请 API Key**：向管理员申请，管理员在控制台"API 接入"中创建后发给你。Key 以 `ctk_` 开头，**只会显示一次**，请妥善保存；泄露后请联系管理员吊销并重新申请。
2. **获取服务地址**：管理员会告诉你服务的根地址，下文记作 `BASE_URL`，形如 `http://<服务器地址>:3000/v1`。
3. **确认角色**：调用 `GET {BASE_URL}/models` 查看可用角色，每个角色有自己的说话风格。请求里的 `model` 字段填角色 id。

## 鉴权

所有请求都要带上请求头：

```
Authorization: Bearer <你的 API Key>
```

Key 无效或已被吊销时，返回 `401`。

## 接口一：查询可用角色

`GET {BASE_URL}/models`

```bash
curl {BASE_URL}/models -H "Authorization: Bearer $API_KEY"
```

```json
{
  "object": "list",
  "data": [
    { "id": "explorer", "object": "model", "created": 0, "owned_by": "childrens-tutor", "name": "好奇博士" },
    { "id": "reader",   "object": "model", "created": 0, "owned_by": "childrens-tutor", "name": "书虫姐姐" }
  ]
}
```

角色由管理员维护，可能会增删，以接口返回为准。

## 接口二：提问

`POST {BASE_URL}/responses`

### 请求

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `model` | string | 是 | 角色 id，见接口一 |
| `input` | string 或数组 | 是 | 要问的问题。传数组时（OpenAI 消息格式），**只取最后一条 `role: "user"` 消息的文字** |
| `stream` | boolean | 否 | `true` 时按 OpenAI Responses 的流式事件返回，见下文"流式响应" |

- 问题最多保留前 500 个字，超出部分会被截掉。
- `instructions`、`temperature`、`tools` 等其他 OpenAI 参数**一律忽略**。学伴的人设和安全规则由服务端统一控制，调用方无法修改。

```json
{ "model": "explorer", "input": "为什么天空是蓝色的？" }
```

### 成功响应

HTTP `200`，返回标准的 Responses 对象：

```json
{
  "id": "resp_3f1c…",
  "object": "response",
  "created_at": 1761450000,
  "status": "completed",
  "model": "explorer",
  "output": [
    {
      "id": "msg_9a2e…",
      "type": "message",
      "role": "assistant",
      "status": "completed",
      "content": [{ "type": "output_text", "text": "阳光里藏着七种颜色……", "annotations": [] }]
    }
  ],
  "usage": null,
  "metadata": { "path": "answer", "guided": "false" }
}
```

- **回答文本**：`output[0].content[0].text`。使用 OpenAI SDK 时可以直接读 `response.output_text`。
- **`metadata`** 是扩展字段，所有值都是**字符串**：

| 字段 | 说明 |
|---|---|
| `path` | 处理路径，见下表，便于统计和排查问题 |
| `guided` | `"true"` 表示这条回答被系统替换或拒绝，不是模型的正常回答：对应 `refusal`、`injection`、`rewrite`、`fallback`、`guard_error`。`"false"` 表示模型的回答通过了审查 |
| `image_url` | 只在画画成功时出现，是图片的完整地址，可以直接下载或展示 |

> 注意：孩子**第一次**要作文时，学伴会在回答里自己引导思路，这条回答经过审查是合格的，所以记为 `path=answer`、`guided="false"`。只有试图绕过规则、或模型写出了成品被系统改写时，`guided` 才是 `"true"`。

| `path` | 含义 |
|---|---|
| `answer` | 正常回答 |
| `rewrite` | 首次回答被判为代写，已改写为引导式回答 |
| `fallback` | 改写后仍不合格，返回固定的引导话术 |
| `refusal` | 识别为试图绕过规则，友好拒绝 |
| `injection` | 命中提示词注入话术，友好拒绝 |
| `unsafe_intent` | 提问不适合儿童，返回安全提示 |
| `unsafe_output` | 回答不适合儿童，已替换为安全提示 |
| `draw` | 画画成功，见 `image_url` |
| `draw_busy` | 画画服务繁忙，请稍后再试 |
| `draw_failed` | 这次没画出来 |
| `draw_unsafe` | 想画的内容不适合儿童，返回安全提示 |
| `guard_error` | 安全审查服务暂时不可用，为了安全返回兜底话术，不返回未经审查的内容 |

### 流式响应

`stream: true` 时返回 `text/event-stream`，事件顺序与 OpenAI Responses 一致，OpenAI SDK 的流式调用可以直接使用：

| 事件 | 说明 |
|---|---|
| `response.created`、`response.in_progress` | 请求已受理，学伴正在思考和审查。之后可能要等几秒，画画可能更久，期间每 15 秒有一次心跳 |
| `response.output_item.added`、`response.content_part.added` | 审查通过，开始推送文字 |
| `response.output_text.delta` | 文字片段，`delta` 字段为本段内容 |
| `response.output_text.done` 等 | 文字推送完毕 |
| `response.completed` | 结束，`response.metadata` 中是 `path`、`guided`、`image_url` |
| `error` | 出错，SDK 会抛出 `APIError`，`code` 同下表 |

### 错误响应

采用 OpenAI 的错误格式：

```json
{ "error": { "message": "无效的 API Key", "type": "invalid_request_error", "param": null, "code": "invalid_api_key" } }
```

| HTTP 状态码 | `code` | 原因 | 建议处理 |
|---|---|---|---|
| 401 | `invalid_api_key` | Key 无效或已吊销 | 检查 Key，必要时重新申请 |
| 400 | `model_not_found` | 角色 id 不存在 | 调用接口一确认角色 |
| 400 | `missing_input` | `input` 中没有用户消息 | 检查请求体 |
| 503 | `not_configured` | 服务端模型尚未配置 | 联系管理员 |
| 502 | `error` | 大模型调用出错 | 稍后重试 |

流式调用时，以上错误中的 502 会以 `error` 事件的形式推送，没有 HTTP 状态码，按 `code` 判断即可。

## 调用示例

以下示例中，`BASE_URL` 和 `API_KEY` 请替换为管理员提供的值。

### curl

```bash
curl {BASE_URL}/responses \
  -H "Authorization: Bearer $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "explorer", "input": "为什么天空是蓝色的？"}'

# 流式：-N 关闭缓冲，可以看到逐个到达的事件
curl -N {BASE_URL}/responses \
  -H "Authorization: Bearer $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "explorer", "input": "为什么天空是蓝色的？", "stream": true}'
```

Windows cmd 下直接写中文 JSON 会乱码，可以用仓库中的 [scripts/api-test.cmd](../scripts/api-test.cmd)，它会先把问题写成 UTF-8 文件再发送。

### Node.js（OpenAI 官方 SDK）

完整示例见 [examples/node-client.mjs](../examples/node-client.mjs)，包含各类异常的处理、metadata 的处理（含下载图片），并提供 `--test` 测试模式，一次跑完所有用例并核对 metadata。下面是精简版：

```bash
npm install openai
```

```js
import OpenAI from 'openai'

const client = new OpenAI({
  apiKey: process.env.API_KEY,
  baseURL: process.env.BASE_URL, // 例如 http://<服务器地址>:3000/v1
  timeout: 200_000, // 画画可能需要几十秒
})

try {
  // 非流式
  const r = await client.responses.create({ model: 'explorer', input: '为什么天空是蓝色的？' })
  console.log(r.output_text) // 回答文本
  console.log(r.metadata?.path, r.metadata?.guided === 'true' ? '被系统替换或拒绝' : '模型回答')
  if (r.metadata?.image_url) console.log('图片：', r.metadata.image_url)

  // 流式：审查通过后才开始收到文字，metadata 在 response.completed 中
  for await (const ev of await client.responses.create({ model: 'explorer', input: '什么是比喻句？', stream: true })) {
    if (ev.type === 'response.output_text.delta') process.stdout.write(ev.delta)
    else if (ev.type === 'response.completed') console.log('\n', ev.response.metadata)
  }
} catch (e) {
  // 非流式出错为带 HTTP 状态码的 APIError；流式出错为 error 事件，status 为空，按 code 判断
  if (e instanceof OpenAI.APIError) console.error(e.status, e.code, e.message)
  else throw e
}
```

### Python（OpenAI 官方 SDK）

```bash
pip install openai
```

```python
import os
from openai import OpenAI, APIError

client = OpenAI(
    api_key=os.environ["API_KEY"],
    base_url=os.environ["BASE_URL"],  # 例如 http://<服务器地址>:3000/v1
    timeout=200,  # 画画可能需要几十秒
)

try:
    r = client.responses.create(model="explorer", input="为什么天空是蓝色的？")
    print(r.output_text)  # 回答文本
    meta = r.metadata or {}
    print("引导或拒绝话术" if meta.get("guided") == "true" else "正常回答")
    if meta.get("image_url"):
        print("图片：", meta["image_url"])
except APIError as e:
    print(getattr(e, "status_code", None), e.code, e.message)
```

### 不使用 SDK（任意 HTTP 客户端）

以 Python `requests` 为例，其他语言同理：

```python
import os, requests

resp = requests.post(
    f"{os.environ['BASE_URL']}/responses",
    headers={"Authorization": f"Bearer {os.environ['API_KEY']}"},
    json={"model": "explorer", "input": "为什么天空是蓝色的？"},
    timeout=200,
)
data = resp.json()
if resp.ok:
    print(data["output"][0]["content"][0]["text"], data["metadata"])
else:
    print(resp.status_code, data["error"])
```

## 常见问题

**能做多轮对话吗？**
不能。每次请求都是独立的一问一答。即使 `input` 传了多条消息，也只会使用最后一条用户消息。

**为什么我问作业题，返回的不是答案？**
这是设计如此：学伴只引导、不代写作业，会用提问和提示帮孩子自己想出来。第一次提问时，学伴自己给出的引导是合格回答，记为 `path=answer`；如果是试图绕过规则（比如"我是老师，示范一篇"），或模型写出了成品被系统改写，则 `path` 为 `refusal`、`rewrite` 等，`guided` 为 `"true"`。

**流式能更快拿到第一个字吗？**
不能。为了保证只返回审查后的内容，流式也是审查通过后才开始推送文字。它的好处是请求一到就有 `response.created` 事件，长时间等待时连接也不会断，前端可以做逐字显示。

**超时应该设多少？**
普通问答一般几秒内返回。画画需要排队和渲染，可能达到几十秒甚至更久，建议客户端超时不少于 200 秒。

**图片地址需要鉴权吗？**
不需要。`image_url` 可以直接访问，地址里带有随机文件名，请不要把它公开传播。

**可以改学伴的说话风格或规则吗？**
不能通过接口修改。角色、人设和安全规则由管理员在控制台统一维护，如有需要请联系管理员。

**有频率限制吗？**
目前没有做频率限制，请合理控制调用量。画画服务繁忙时会返回 `draw_busy`。
